# GD-008 — Set 2 açılışı: track iskeleti + S2-L1

## 1. Goal

Set 2 "Grafik ve Piyasa Okuryazarlığı"nı **açmak**: `grafik-ve-piyasa` track'i
kurulur ve setin ilk dersi (S2-L1) uçtan uca yayına girer.

**Neden ikisi bir arada:** iskelet tek başına teslim edilemez. Seed sözleşmesi
**her ders için** üç derinlik katmanı, sabit yapı (M1/M2), 9 soruluk mini test
ve "tavsiye değildir" çerçevesi şart koşuyor; "8 boş ders" yaratmak bu kuralları
anında kırar. Bir track'in de içi boş bırakılamaz. Set 0 da böyle ilerledi:
track bir kez kuruldu, dersler tek tek indi.

D-024 gereği bu GD, **20 derslik kalan kapsamın ilk halkası** — Set 2'nin
tamamı değil.
